HOW TO VIEW
-----------
After unzipping, use EITHER method:

METHOD 1 — EASIEST (styles embedded)
  Double-click:  index.html
  Styles are built into the page and should display immediately.

METHOD 2 — BEST NAVIGATION
  Double-click:  START-MOCKUP.bat  (Windows)
                 START-MOCKUP.sh   (Mac/Linux)
  Opens in browser at http://127.0.0.1:5500/


TROUBLESHOOTING
---------------
• Still looks like plain text with bullet lists?

  → Right-click index.html → Open with → Chrome or Edge.

• Navigation between pages broken?
  → Use START-MOCKUP.bat instead of opening index.html directly.
