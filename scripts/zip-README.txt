MINDFULNESS CANDLE COLLECTION — WEBSITE MOCKUP
=============================================

HOW TO VIEW (RECOMMENDED — REQUIRED FOR FULL STYLING)
-----------------------------------------------------
1. Unzip the entire folder
2. Double-click:
     Windows:  START-MOCKUP.bat
     Mac/Linux: START-MOCKUP.sh
3. Your browser opens at http://127.0.0.1:5500/

IMPORTANT: Do NOT double-click index.html directly.
This mockup must be viewed through the local server so CSS and
navigation load correctly.

Requirements: Python 3 or Node.js (usually preinstalled).


TROUBLESHOOTING
---------------
• Page looks unstyled (plain text, bullet lists)?
  → Close the browser tab, double-click START-MOCKUP.bat again.
  → Make sure you unzipped the FULL folder (must contain _astro folder).

• "Port already in use" error?
  → Close other apps using port 5500, or edit START-MOCKUP.bat
    and change PORT=5500 to PORT=8888.
