MINDFULNESS CANDLE COLLECTION — WEBSITE MOCKUP
=============================================

HOW TO VIEW (RECOMMENDED)
-------------------------
Double-click one of these files after unzipping:

  • START-MOCKUP.bat   (Windows)
  • START-MOCKUP.sh    (Mac / Linux)

This opens the mockup at http://localhost:8080 with full styling and navigation.

Requirements: Python 3 or Node.js (usually already installed).


HOW TO VIEW (ALTERNATIVE)
-------------------------
Open index.html directly in Chrome, Edge, or Firefox.
All asset paths are relative, so styles should load from the unzipped folder.
