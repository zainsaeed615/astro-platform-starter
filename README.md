# UltraHMB™

Marketing site for UltraHMB™ (β-Hydroxy β-MethylButyrate Calcium) by Vesta® Nutra.

Built with Astro, Tailwind CSS, and Netlify.

## Pages

- `/` — Home
- `/about` — About / The Science of HMB-Ca
- `/applications/muscle-growth-recovery`
- `/applications/healthy-aging`
- `/applications/cognitive-wellness`
- `/faq`
- `/contact`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
