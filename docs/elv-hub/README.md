## Meeting requirements → structure impact

| Theme | Requirement | Impact |
|-------|-------------|--------|
| Process | Hierarchy / journey first; no rushing live mock-ups | This document |
| Visitor-first | Design for someone checking solutions + credibility + inquiry | Journey-led homepage |
| Message speed | 1–2 sentences of clarity → icons → deeper solution cards | H1 → H3 → H4 |
| Credibility early | SMERK-style “Trusted by” early | H2 logo strip |
| Navigation | No Home, no Search; Solutions-led; Contact Us CTA; About not legacy-first | Nav options |
| Header | AVI-SPL-style transparent → solid on scroll; thinner bar | Header options |
| Utility bar | Phone/email/location feels legacy — keep as optional | U1 / U2 |
| Visual tone | Too much white (later phase) | Logged, not decided here |

## Recommended homepage journey (Option A)

1. **Hero** — Instant clarity + primary Contact CTA  
2. **Trusted by** — Client / partner logos  
3. **Solutions overview** — Icons only  
4. **Solutions in depth** — Image + short line + Read more  
5. **How we work** — Design → Supply → Install → Maintain  
6. **Selected projects** — Landmark proof  
7. **Sectors** — Education / Hospitality / Oil & Gas / Corporate / Government  
8. **Why ELV Hub** — Certifications / partnerships (short)  
9. **Final CTA** — Contact / Call / WhatsApp  

**Option B:** Projects / references earlier  
**Option C:** Solutions first, trust strip later
